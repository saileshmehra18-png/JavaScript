# JavaScript Learning

A collection of exercises and small projects documenting my progress with **JavaScript** and frontend development.

## Topics and practice

The repository is organised into topic-based folders, including:

- Variables and data types
- Boolean logic and conditional statements
- Functions and objects
- Arrays and loops
- DOM manipulation
- Small website exercises

## Working with the code

Most exercises are browser-based. Open the relevant HTML file in a browser, or use the VS Code Live Server extension where appropriate.

## Goal

Build a solid JavaScript foundation through consistent practice and small projects.
